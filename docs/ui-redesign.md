# UI/UX 개편 이력 (2026-09-15)

이 문서는 이 세션에서 실제로 확인/적용된 상태만 남깁니다. 이전 버전(색상·radius·버튼 스타일만 바꾼
1차 패스의 기록)은 그 패스 자체가 반려되어 이번 패스로 대체되었습니다.

## 범위와 보존

단일 페이지 앱, `showScreen`/`data-mode` 라우팅. Supabase/API 계약, 환경변수, 기존 데이터 구조는
건드리지 않았습니다. `src/worker.js`는 diff 없음.

## 이번 패스에서 확인한 실제 버그와 원인

1. **한글 제품명이 한 글자씩 세로로 깨짐** (처방약 확인 화면 등)
   - 근본 원인: `.flow-list button{width:100%}`가 하위 몇 단계 아래 있는 `.save-heart`(♡ 저장)
     버튼까지 매칭해 그 버튼을 100% 너비로 늘려버렸고, 옆에 있던 이름 텍스트 span은 `flex:1`로
     남은 공간을 계산했지만 남은 공간이 0이 되어 버렸습니다. 거기에 `overflow-wrap:anywhere`가
     겹치며 글자 단위로 줄바꿈된 것처럼 보였습니다.
   - 조치: `.flow-list button` → `.flow-list>button` (직계 자식만), `body`에
     `word-break:keep-all` 추가, `.rx-choice>span{flex:1;min-width:0}` 명시.

2. **검색 결과/보관함 리스트 버튼 내부 텍스트가 여러 칸으로 깨짐** (제품명·제조사·포장단위가
   나란히 눌려 보임)
   - 근본 원인: 전역 `button{display:inline-flex}` 기본 규칙이 있어서, 이름+제조사+포장정보처럼
     여러 줄(`<small>` 블록)을 쌓아 보여주는 버튼까지 flex-row로 바뀌어 그 줄들이 나란히 배치됐습니다.
   - 조치: 전역 버튼 기본 규칙에서 flex 제거(아이콘+라벨이 필요한 개별 컴포넌트가 스스로
     `display:flex`를 선언). `.save-row` 누락된 스타일 복원.

3. **홈 "최근 확인한 약" 가로 캐러셀 → 세로 리스트**
   - `overflow-x:auto` 캐러셀 자체는 버그가 아니었지만, Phase 7 스펙에 따라 세로 3개 + "전체
     보기"로 교체.

4. **버튼이 눌리지 않는다는 보고**
   - 실제로 재현된 것은 위 1/2번과 같은 원인(0px로 눌린 요소는 시각적으로도 탭하기 어려움)이며,
     별도의 이벤트 리스너 누락/overlay 문제는 발견하지 못했습니다.

## 성능

홈 진입 시 실제 네트워크 요청을 측정(추정 아님, Playwright로 확인):
- **개편 전**: `three.module.js`, `OrbitControls.js`, `tablet-geometry.js`, `pouch-crop.js`,
  `dose-calc.js`가 홈 화면에서도 무조건 다운로드됨.
- **개편 후**: 홈 진입 시 요청은 `index.html`/`ui.css`/`medicine-flow.js`/`app.js` 4개뿐.
  3D 엔진은 알약 화면 진입 시(`ensureThree3D`), dose-calc는 알약/액체약/처방전 화면 진입 시
  (`ensureDoseCalc`), pouch-crop은 액체약 화면 진입 시(`ensurePouchCrop`)에만 지연 로드됩니다.
  세 함수 모두 멱등(idempotent) - 여러 번 불려도 한 번만 로드합니다.

## 화면 개편

- **홈**: 인사말 + 검색 CTA + 처방전 촬영 CTA + 빠른 확인 3칩 + 최근 확인(세로 3개+전체보기).
  예전 "약 정보 빠르게 보기" 중간 허브 화면(`screenQuick`)은 제거 - 하단 nav "약 검색"이 검색
  화면으로 직접 이동합니다. 내 약 보관함은 설정(내 정보) 화면에서 진입합니다.
- **하단 네비게이션**: 홈/처방전/약 검색/내 정보 4개, 동일한 비중(예전의 raised-circle 강조 제거).
- **약 검색**: 검색 단계 ↔ 결과 단계를 모든 화면 크기에서 동일하게 전환(예전엔 데스크톱에서만
  검색+결과를 나란히 보여줬음). 결과 단계에서는 상단이 "🔍 다른 약 검색하기" 한 줄로 줄어듭니다.
  제품 요약 카드(크기/맛·복용감/복용방법/보관방법 4칸)가 3D보다 먼저 보이고, 3D·계산·상세정보는
  오른쪽(데스크톱)/아래(모바일) 도구 카드에 있습니다.
- **처방전**: 대시보드형 헤더 + 등록 영역, 최근 처방전은 압축된 한 줄 리스트.
- **프로필**: 읽기 모드가 기본이고 "수정"을 눌러야 폼이 나타납니다.

## 아직 하지 못한 것 (다음 단계로 남김)

사용자가 이번 요청에서 제시한 Phase 8~12(검색 결과를 저장 버튼 없는 순수 리스트로, 상세 화면을
"Medicine Identity Strip + Dose Scale" 컨셉으로, 용량 가이드를 별도 라우트로, 처방전 OCR을
한 약씩 넘기는 단계형 플로우로, 프로필을 필드별 bottom sheet로)는 이번 패스에서 구현하지
않았습니다. 기존 기능을 먼저 안정화하는 것을 우선했습니다.
