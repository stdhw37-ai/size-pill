# 홈·처방전·액체약 UX 구현 보고

## 구조 및 기존 기능 유지

- `index.html`: 홈 카드 세로 3개, 중앙 720px 제한, 최근 기록은 아래. 기존 하단/상단 탐색 유지.
- `public/app.js`: 기존 `showScreen`, `selectMedicine`, 공식 검색, 맛/향 추출을 재사용. 처방전 목록과 선택 상태는 메모리에만 유지.
- `src/worker.js`: `/api/liquids`만 제품 허가정보 검색으로 확장. 알약 API·캐시 키·Supabase 테이블과 기존 데이터 보존.
- 기존 3D·화면 보정·직접 치수 입력 및 컵 계산식 `p` / `0.45p + 0.55p²` 유지. 카메라는 접힌 보조 기능으로 이동하고 이탈/접기 시 스트림 종료.
- Capacitor 구조 유지. iOS 카메라 권한 설명만 처방전 용도를 포함하도록 수정. 기존 `NATIVE_API_BASE`의 배포 URL 자리표시는 유지되어 실제 네이티브 검색 전 URL 설정이 필요함.

## OCR 및 개인정보

[Tesseract.js 공식 문서](https://github.com/naptha/tesseract.js/blob/master/docs/local-installation.md)의 로컬 리소스 경로 방식을 사용. 한국어/영어 모델, Web Worker, WASM을 빌드 산출물에 포함하고 사용 시 로딩한다. 외부 OCR API와 Supabase Storage를 사용하지 않는다.

카메라 촬영 / 사진 선택 → 기기 내 OCR → 약명·함량 수정 → 공식 후보 검색 → 사용자 체크 → 비교 흐름이다. 전체 OCR 문장은 서버로 보내지 않는다. 제형 접미사로 약명 후보를 추출하고 음절 사이 공백을 정리한다. 사용자가 확인한 약명·함량 검색어만 서버로 전달한다. 투여량·횟수·제조사 칼럼 자동 구조화는 구현하지 않았으며 복용량 계산에 사용하지 않는다.

20MB 이미지 입력 제한, 긴 변 2400px 축소, 120초 처리 제한. 완료/오류/취소 때 Worker 종료, Blob URL 해제, 캔버스 비우기, 파일 입력 초기화. 원본 사진 보관함은 변경하지 않는다. 지우기 버튼으로 인식문/후보/선택을 지울 수 있다. 처방전 데이터는 localStorage에 저장하지 않으며, 기존 개별 제품 화면을 연 경우에만 기존 최근 확인한 약 기록이 적용된다.

작은 글씨·흐림·접힘·회전·손글씨·복잡한 표에서 누락이나 오인이 가능하다. JPG/PNG 재선택과 직접 입력을 제공한다. 실제 처방전 표본으로 정확도를 측정하지 않았으므로 정확도 수치를 제시하지 않는다. 영문 약명이나 제형 접미사가 없는 이름은 자동 추출에서 누락될 수 있다.

## 공식 제품 매칭과 비교

품목명의 공백을 정규화하고 함량 숫자 영역의 `O`를 `0`으로 보정한다. 약명으로 공식 후보를 검색해 제품명·함량 일치에 높은 순위를 준다. 후보가 많으면 함량을 포함한 추가 검색을 합치고, 결과가 없으면 마지막 글자를 뺀 검색을 한 차례 시도한다. 일반적인 오타 전체를 해결하는 사전 기반 fuzzy 엔진은 아니다.

어떤 후보도 자동 체크하지 않는다. 다른 함량 후보를 숨기지 않으며 제조사·공식 치수와 함께 제시한다. 중복 품목번호는 선택 상태를 공유한다. 여러 선택 약을 같은 px/mm 비율의 단순 실루엣으로 비교하고, 클릭하면 기존 개별 3D로 연결한다. 비교 화면은 상대 비율이며 보정된 실물크기를 주장하지 않는다. 누락 치수를 만들어내지 않는다.

## 액체약과 안전 표시

[식약처 제품 허가정보](https://www.data.go.kr/data/15095677/openapi.do)의 `PACK_UNIT`에서 포장 용량을 선택한다. `1/2`, `1/3`, `1/4`, `2/3`, `3/4`, 소수/백분율 직접 입력 지원. 계산은 `선택한 총 mL × 분율`, 소수점 한 자리 반올림. 모형의 높이는 단순 분율로 표시하며 기존 카메라 컵 계산과 독립적이다.

포/병/컵 모형 선택 및 포장 용량 직접 입력은 보조 설정에 배치. 모형은 공식 포장 치수에 기반한 재현이 아니다. 공식 이미지에 용기 경계·원근·높이 정보가 없으므로 자동 사진 overlay는 적용하지 않았다.

화면에 “대략적인 분할 위치입니다”, “시각적 참고용”, “실제 mL 위치가 아닙니다” 및 전용 계량기 사용 안내를 표시한다. 잘못된 분율은 적용하지 않고 오류와 마지막 유효한 값 유지 안내를 한다. 총 용량이 없거나 유효하지 않으면 mL 계산값을 표시하지 않는다. 건조시럽 재구성이나 소아·고위험약의 용량 결정을 지원하지 않는다.

맛/향은 기존 `buildFlavorInfo`를 재사용해 공식 성상(CHART)·제품허가 성상·첨가제에 명시된 맛/향 표현만 표시한다. 사진 색상이나 성분으로 추측하지 않는다. 제품 상세에 출처와 근거 텍스트를 연결한다.

## 검증

- `npm test`: 기존 검색·캐시·식별정보·3D 연결·화면 보정·카메라 및 새 처방전 다중 선택·비교·공백 추출·액체약 분율·이전 요청 경합 테스트.
- `npm run check`: 빌드 및 Wrangler 배포 dry-run. 운영 배포는 하지 않음.
- 실제 식약처 응답: 코미시럽 `500mL/병`, 텔미암정40/10mg `12.32 × 6.79 × 4.14 mm` 확인.
- Chromium 1440×1000, WebKit iPhone 13 프로필 390×664: 세로 홈, 체크 전 선택 0개, 다중 비교, 기존 3D 연결, 20mL × 1/3 = 6.7mL, 가로 넘침 없음 확인.
- 브라우저 합성 한국어 이미지로 실제 OCR Worker/WASM 실행 및 인식 → 약명 추출 확인. OCR 중 외부 HTTP 요청 0건 확인.
- iPhone 실기기·실제 카메라/사진 권한·네이티브 iOS/Android 빌드·실제 처방전 정확도는 미검증. WebKit 프로필 검증은 실기기 Safari 검증과 다름.
